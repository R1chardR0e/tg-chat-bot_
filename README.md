# TG Chat Bot

Telegram-бот для групповых чатов с контекстными ответами, долговременной памятью
и семантическим поиском по истории сообщений.

Бот сохраняет сообщения в локальной SQLite-базе, собирает релевантный контекст и
отвечает, когда его упоминают, задают вопрос или продолжают диалог ответом на его
сообщение. Для смыслового поиска используется FAISS, а обращение к языковой модели
вынесено в отдельный слой с поддержкой IO.Net и Mistral.

## Возможности

- работа в групповых чатах через `aiogram`;
- реакция на упоминание, вопросительный знак и ответ на сообщение бота;
- хранение пользователей, чатов и сообщений в SQLite;
- контекст из недавних сообщений и связанной цепочки ответов;
- семантический поиск по сообщениям с помощью FAISS;
- команда `/search` и защищённый HTTP API для поиска;
- переключаемые провайдеры генерации: IO.Net и Mistral;
- опциональное обновление пользовательских профилей;
- хранение времени в UTC с преобразованием для показа пользователю;
- загрузка истории чата через отдельный скрипт Pyrogram.

## Архитектура

```text
Telegram -> aiogram -> обработчики -> контекст -> LLM-провайдер
                    |             |
                    |             +-> FAISS
                    +----------------> SQLite

HTTP-клиент -> FastAPI -> FAISS -> результаты поиска
```

Основные компоненты:

- `bot.py` — запуск Telegram-бота и middleware сохранения сообщений;
- `handlers/` — команды и логика ответов;
- `database/` — схема SQLite и операции с данными;
- `embeddings/` — генерация эмбеддингов, FAISS-индекс и профили;
- `api/` — защищённый REST API поиска;
- `scripts/` — загрузка истории, миграция времени и обслуживание индекса.

## Требования

- Python 3.10 или новее;
- токен Telegram-бота;
- ключ выбранного LLM-провайдера;
- `API_ID` и `API_HASH` Telegram только для загрузки истории;
- API-ключ эмбеддингов, если включён семантический поиск.

## Быстрый запуск

Создайте виртуальное окружение и установите зависимости:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Скопируйте шаблон настроек:

```powershell
Copy-Item .env.example .env
```

Заполните как минимум `BOT_TOKEN`, параметры выбранного провайдера и список
`CHAT_IDS`. Затем запустите бота:

```powershell
python bot.py
```

При первом запуске SQLite-база и необходимые таблицы создаются автоматически.

## Команды Telegram

- `/start` — краткое приветствие;
- `/help` — справка по доступным возможностям;
- `/search <запрос>` — поиск похожих сообщений в FAISS-индексе.

Кроме команд бот отвечает на сообщения с настроенными обращениями, на вопросы и на
ответы к собственным сообщениям.

## HTTP API

Запустите сервер поиска отдельно:

```powershell
python -m api.server --host 127.0.0.1 --port 8000
```

Все запросы должны содержать заголовок `X-API-Key` со значением
`API_ACCESS_TOKEN`.

Доступные маршруты:

- `POST /api/v1/search` — поиск по всем проиндексированным чатам;
- `POST /api/v1/search/{chat_id}` — поиск в указанном чате;
- `GET /api/v1/index/status` — состояние FAISS-индекса;
- `POST /api/v1/index/sync` — синхронизация индекса с SQLite;
- `GET /` — информация о сервисе.

Интерактивная документация доступна по адресу `http://127.0.0.1:8000/docs`.

## Основные настройки

| Переменная | Назначение |
| --- | --- |
| `BOT_TOKEN` | токен Telegram-бота |
| `CHAT_IDS` | разрешённые ID чатов через запятую |
| `API_PROVIDER` | провайдер ответов: `io_net` или `mistral` |
| `IO_NET_API_KEY` | ключ IO.Net для ответов и эмбеддингов |
| `MISTRAL_API_KEY` | ключ Mistral при выборе этого провайдера |
| `API_ACCESS_TOKEN` | ключ доступа к HTTP API |
| `ENABLE_EMBEDDING` | включает FAISS и семантический поиск |
| `ENABLE_LEARNING` | включает обновление профилей пользователей |
| `DB_PATH` | путь к SQLite-базе |
| `VECTOR_DB_PATH` | путь к FAISS-индексу |

Полный набор параметров с безопасными примерами находится в `.env.example`.

## Служебные команды

```powershell
# Построить недостающие эмбеддинги
python scripts/build_embeddings.py

# Предварительно показать объём обработки
python scripts/build_embeddings.py --dry-run

# Загрузить историю разрешённых чатов
python scripts/collect_chat_history.py

# Перевести старые временные метки в UTC
python scripts/migrate_timestamps_to_utc.py
```

```powershell
python -m compileall -q api database embeddings handlers scripts utils bot.py config.py

```
